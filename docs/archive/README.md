# Archive

Working documents from the project's history, kept for reference. They were written in
Italian before the project went public and are not maintained: paths, numbers and plans
inside them may be out of date. The current documentation is in [docs/](../README.md).

| Folder | Contents |
|--------|----------|
| `spec/` | The original full functional specification of the engine. |
| `editor/` | Editor audit report (273 findings), improvement plan and "Editor Pro" plan. |
| `build/` | Analysis and changelog of the desktop build system. |
