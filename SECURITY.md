# Security policy

## Supported versions

HiddenIndexEngine is in active pre-1.0 development. Only the latest version published
on the `main` branch receives security fixes.

| Version | Supported |
|---------|-----------|
| `main` (0.1.x) | yes |
| earlier tags | no |

## Reporting a vulnerability

**Do not open a public issue for a vulnerability.**

Use GitHub's private channel:
[Security Advisories](https://github.com/indecenti/HiddenIndexEngine/security/advisories/new).

In the report include:

- a description of the problem and its impact;
- steps to reproduce it (a proof of concept if available);
- version, operating system and Python version;
- a proposed fix, if you have one.

Indicative timing: acknowledgement within 7 days, status update within 30 days. The
project is maintained by one person in their spare time: there are no formal SLAs and
no bug bounty.

## Relevant attack surface

Areas where a report is especially useful:

- **`web_platform/server.py`** — HTTP server with signed-cookie authentication
  (HMAC-SHA256), PBKDF2 password hashing. Experimental component: sessions, path
  traversal on game uploads, authorization of the admin endpoints.
- **Scene and catalog loading** (`engine/scene_loader.py`,
  `engine/catalog_manager.py`) — a hostile `scene.json` or `objects_catalog.json`
  could attempt path traversal through the `icon` and `background` fields, or
  exhaust memory with out-of-scale dimensions.
- **Asset import in the editor** — decoding of untrusted images, writes outside the
  game directory.
- **Web export** (`editor/web_exporter.py`) — content injection into the generated
  HTML/JS bundle from scene data.
- **Save game deserialization** (`engine/save_manager.py`).

## Out of scope

- Crashes or `Traceback`s without security consequences: open a regular issue.
- Vulnerabilities in upstream dependencies (pygame, SDL, numpy, opencv): report them
  to the respective projects. If a version pin is needed here, open an issue.
- The signing key generated by `web_platform/server.py` on first start is written to
  `web_platform/config.json`, which is excluded from version control. If you committed
  that file by mistake, rotate the secret: that is not a bug in the project.
- Attacks that require physical access to the machine or already-obtained
  administrator privileges.
