PROBLEMA:
  • Pacchetto ZIP: 2.8 GB ❌
  • Dovrebbe essere: ~100-150 MB ✅
  • Root cause: PyInstaller includeva games/ e engine/ ricorsivamente

ROOT CAUSE IDENTIFICATA:
  editor/build_system.py linea 308 (PRIMA):
    "-p", str(temp_dir),  # ❌ Aggiungeva temp_dir intero a PYTHONPATH!

  Questo causava:
    • PyInstaller includeva games/villa_segreta/ (35MB) nell'EXE
    • PyInstaller includeva engine/ nell'EXE
    • main.exe diventava 2.8GB anziché 145MB
    • ZIP finale era 2.8GB anziché 98MB

SOLUZIONE IMPLEMENTATA:
  1. ✅ Rimosso "-p", str(temp_dir) da PyInstaller args
  2. ✅ Aggiunto "--collect-all=engine" (solo module engine, games esterni)
  3. ✅ Aggiunte esclusioni: *.autosave, *.pyc, .git*, *.bak, *.tmp, *.log
  4. ✅ Validazione EXE: fallisce se >500MB con messaggio chiaro
  5. ✅ Validazione ZIP: fallisce se >500MB con messaggio chiaro
  6. ✅ Filtraggio durante ZIP: niente file sviluppo
  7. ✅ Logging dettagliato di ogni componente
